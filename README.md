# Flora — Flower Shop

Адаптивний вебсайт квіткового магазину, створений за допомогою HTML, CSS та JavaScript.

## Використані технології

- HTML5
- CSS3
- JavaScript (ES6+)
- Axios
- JSON Server

## Запуск проєкту

1. Встановіть залежності:

```bash
npm install
```

2. Запустіть JSON Server:

```bash
npx json-server --watch db.json --port 3000
```

3. Відкрийте проєкт за допомогою Live Server або іншого локального сервера.
